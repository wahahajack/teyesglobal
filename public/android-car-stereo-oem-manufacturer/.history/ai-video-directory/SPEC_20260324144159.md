# AI Video Generation Models Directory - Specification

## Concept & Vision

A sleek, modern directory showcasing the best AI video generation models available in 2024-2025. The website feels like stepping into a futuristic control room—dark, sophisticated, with glowing accents that evoke the cutting-edge nature of AI technology. Each tool is presented as a "station" in a gallery of innovation, inviting exploration.

## Design Language

### Aesthetic Direction
Dark mode cyberpunk-meets-minimalism aesthetic. Think Tron meets Apple—sophisticated darkness with precise, glowing highlights. Cards float with subtle depth, and interactions feel smooth and responsive.

### Color Palette
- **Primary Background**: `#0a0a0f` (deep space black)
- **Secondary Background**: `#12121a` (card surfaces)
- **Accent Primary**: `#7c3aed` (vivid purple - AI/tech feel)
- **Accent Secondary**: `#06b6d4` (cyan - innovation)
- **Accent Gradient**: Linear from `#7c3aed` to `#06b6d4`
- **Text Primary**: `#f8fafc` (near white)
- **Text Secondary**: `#94a3b8` (muted gray)
- **Success**: `#10b981` (emerald)
- **Border**: `rgba(255,255,255,0.1)`

### Typography
- **Headings**: Inter, 700 weight, tight letter-spacing (-0.02em)
- **Body**: Inter, 400/500 weight
- **Monospace accents**: JetBrains Mono for tags/technical details
- **Scale**: 48px hero → 24px section → 18px card titles → 14px body

### Spatial System
- Base unit: 8px
- Section padding: 80px vertical
- Card padding: 24px
- Grid gap: 24px
- Border radius: 12px (cards), 8px (buttons), 24px (hero elements)

### Motion Philosophy
- Page load: Staggered fade-up animations (300ms each, 100ms delay between)
- Cards: Scale 1.02 + glow intensification on hover (200ms ease-out)
- Buttons: Background gradient shift + subtle scale (150ms)
- Scroll: Parallax hero background, sticky nav with backdrop blur
- All transitions use cubic-bezier(0.4, 0, 0.2, 1)

### Visual Assets
- Icons: Lucide icons via CDN (consistent stroke weight)
- Card images: Gradient placeholder backgrounds with subtle noise texture
- Decorative: Floating gradient orbs in hero, grid pattern overlay

## Layout & Structure

### Hero Section
- Full viewport height minus nav
- Large headline with gradient text effect
- Animated subtitle typing effect
- Floating decorative elements (gradient orbs)
- CTA button with glow effect
- Grid pattern overlay for depth

### Navigation
- Fixed position with backdrop blur on scroll
- Logo on left, nav links center, CTA right
- Mobile: Hamburger menu with slide-in drawer

### Filter Bar
- Sticky below nav when scrolling
- Filter chips: All, Text-to-Video, Image-to-Video, Video Editing, Free, Paid
- Active state with gradient background
- Smooth horizontal scroll on mobile

### Models Grid
- Responsive grid: 3 columns desktop, 2 tablet, 1 mobile
- Cards with hover lift effect
- Each card shows: Logo placeholder, name, short description, pricing badge, feature tags, action button

### Footer
- Minimal: Logo, copyright, social links
- Gradient border top

## Features & Interactions

### Core Features
1. **Model Cards**: Display name, description, pricing model, key features, external link
2. **Filtering**: Filter by category (text-to-video, image-to-video, etc.) and pricing
3. **Search**: Real-time search across model names and descriptions
4. **Responsive**: Fully responsive from mobile to desktop

### Interaction Details
- **Card Hover**: Scale up, border glow intensifies, shadow deepens
- **Filter Click**: Instant filter with fade animation on grid items
- **Search**: Debounced (300ms) filtering as user types
- **Button Click**: Ripple effect with gradient
- **Link Hover**: Underline animation from left

### Edge Cases
- **Empty Search Results**: Friendly message with suggestion to clear filters
- **No Results for Filter**: Show "No models match this filter" with reset option

## Component Inventory

### Navigation Bar
- States: Default (transparent), Scrolled (blur background)
- Mobile: Hamburger transforms to X

### Filter Chip
- States: Default (outline), Active (gradient fill), Hover (slight glow)

### Model Card
- States: Default, Hover (elevated + glow), Focus (outline)
- Elements: Image area, title, description (2 lines max), pricing badge, feature tags, CTA button

### Search Input
- States: Default, Focused (border glow), Filled
- Clear button appears when text present

### CTA Button
- States: Default (gradient), Hover (brighter + scale), Active (pressed), Disabled (muted)

### Footer
- Static component with social icon links

## Technical Approach

- **Framework**: Vanilla HTML, CSS, JavaScript (no build step needed)
- **CSS**: Custom properties for theming, CSS Grid + Flexbox, @keyframes for animations
- **JS**: ES6+, modular functions, event delegation
- **External Resources**:
  - Google Fonts: Inter, JetBrains Mono
  - Lucide Icons via CDN
- **Responsive**: Mobile-first, breakpoints at 640px, 768px, 1024px, 1280px
